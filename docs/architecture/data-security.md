# 데이터와 보안 경계

저장·삭제·권한과 Renderer 실행 경계의 원본 문서다.

## 데이터와 보안 경계

### 저장 위치

| 위치 | 데이터 | 기본 처리 |
| --- | --- | --- |
| 클라이언트 메모리 | 마이크 PCM Ring Buffer·확정 전후 발화 음성·서버 TTS 응답 오디오·영상 프레임·손 좌표·세션·호출 전 창 | 오디오 버퍼 길이·수명을 제한하고 업로드 완료·재생 종료·취소·권한 철회 후 폐기. 완료 발화만 서버에 전송하며 대기 음성·원시 영상은 전송하지 않음 |

| 서버 비밀 저장 | 캘린더 갱신 토큰·외부 API 키 | 서버 측 암호화·접근 제한. 로그에 노출하지 않음 |

### 주요 데이터 모델

| 엔터티 | 핵심 데이터 |
| --- | --- |
| User | 서버 `userId`, 로그인 `loginId`, 서버 전용 비밀번호 해시, 시간대, 수집 설정. 공개 사용자 정보에는 비밀번호 해시·토큰 제외 |
| Device | 소유 사용자, OS·앱 버전, 마지막 연결, 기능 버전 |
| Request·ToolExecution | 요청·실행 ID, 대상 기기, 도구, 기한, 상태, 관측 결과·오류 |
| AppActivity | 이벤트 ID, 앱 ID, 발생 시각, 기기, 실행 출처, 실제 결과 |
| Recommendation·Feedback | 추천 대상·근거 기록 범위·유효 시간·노출·의사결정·실행 연결 |
| CalendarConnection | 제공자·계정 식별자·권한·토큰 참조·연결 버전·마지막 조회 |
| DeletionJob | 삭제 범위·요청 시각·대기 기록 차단·집계 재계산·처리 상태 |
| OperationalEvent | 요청 연계 ID, 오류 유형, 응답 시간, 모델별 실제 사용량 |

기본 MVP는 조회한 일정 원문을 장기간 별도 저장하지 않는 안으로 한다. 캐시가 필요하면 TTL과 연결 해제 시 폐기 기준을 먼저 정한다. 기록 삭제 이후 오프라인 기기가 이전 대기 기록을 다시 올리지 않도록 삭제 기준 시각·범위와 수집 정책 버전을 동기화한다.

서버 STT 사용 시 완료 발화가 기기 밖으로 전송된다는 점을 사용자 설정과 권한 안내에 명확히 표시한다. 음성 바이트·인식 텍스트·TTS 오디오는 운영 로그와 오류 보고에 포함하지 않는다. 서버가 외부 음성 제공자를 사용하게 되면 전송 대상·지역·보관 정책을 별도로 결정하고 사용자 안내에 반영한다.

### 인증 정보와 계정 격리

기능·화면 정책은 [계정 인증](../features/auth.md)을 따른다. 인증 저장소는 Main 내부 `CredentialStorePort` 뒤에 두며 Electron `safeStorage` 등 OS 보호 수단의 가용성을 확인한다. 보호 저장이 불가능하거나 실패하면 로그인 유지 불가를 알리고 평문으로 대체하지 않는다. 현재 실행의 로그인 성공과 재실행 복구를 위한 저장 성공은 별도로 확인한다.

비밀번호·재입력은 폼 처리에 필요한 동안만 보유하고 전역 UI 상태·localStorage·설정 파일·대기열·로그·오류 보고에 넣지 않는다. 재입력은 UI에서만 검증하고 Main과 서버로 보내지 않는다. Main은 비밀번호를 HTTPS 인증 요청에만 사용하고, 세션 비밀을 `AuthSnapshot`·일반 상태 이벤트·Media API·Worker에 전달하지 않는다. Renderer가 서버 인증을 우회하거나 토큰을 직접 저장·갱신하지 않는다.

서버는 비밀번호를 복호화 가능한 값으로 저장하지 않고 비밀번호 전용 해시를 사용한다. 해시 알고리즘·파라미터·자격 증명 수명은 서버 구현 단계에서 확정한다. 로컬 로그인 유지에는 비밀번호 대신 서버가 발급한 세션 복구용 자격 증명을 사용한다.

기록·삭제 요청·캘린더·추천과 전송 대기열은 서버의 `userId`를 소유자로 구분한다. 로그아웃·계정 전환 시 UI 구독과 계정 데이터를 분리하며 이전 사용자의 대기 데이터를 새 인증으로 전송하지 않는다. 이전 계정 데이터의 보관·삭제는 수집·삭제 정책에 따르며 다른 사용자에게 노출하지 않는다. 인증 세대가 바뀐 요청·응답·명령은 폐기한다.

참고: [Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage), [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html).

### 로컬 오디오 처리 경계

수집한 PCM은 Media Renderer의 30초 순환 버퍼와 Main의 처리 중 메모리에만 있다. 듣는 쪽이 없으면 Main은 PCM을 버리고 어디에도 저장하지 않는다. 발화 하나를 받으면 VAD를 멈추고 버퍼를 비운 뒤 마이크 사용권을 반납하며, 완료된 발화 바이트만 호출한 쪽에 남는다. 오디오는 로그·진단 출력에 넣지 않는다(셀프테스트도 길이와 크기만 출력한다).

### 카메라·마이크 권한 경계

Electron session의 권한 처리기는 기본 거부다. 카메라·마이크는 비표시 Media Renderer가 Main이 센서를 시작하는 중이거나 사용 중인 종류에 대해서만 허용하며, UI 창·다른 문서·그 밖의 모든 권한 요청은 거부한다. Chromium의 가짜 UI 승인 스위치는 처리기를 우회하므로 개발용 가짜 장치에서도 쓰지 않는다. macOS 사용 목적 문구는 패키징 설정에 둔다.

### 실행과 UI 경계

Renderer는 `contextIsolation`과 제한된 `contextBridge` API를 사용하고 Node.js 직접 접근을 허용하지 않는 구성을 기본으로 한다. Main은 IPC 발신 창·인자·기능 범위를 검증한다. 외부 콘텐츠나 LLM 출력은 실행 권한이 되지 않으며, 등록 도구·허용된 앱·검증된 URL 범위 안에서만 실행한다.

미로그인·인증 확인 중에는 화면 숨김만으로 접근을 제한하지 않고 Main이 현재 인증을 검사한다. 인증 전용 연산과 중지·정리·종료를 제외한 주요 기능의 IPC·트레이·단축키·OS 실행을 차단한다.
