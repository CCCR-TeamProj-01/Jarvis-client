# Server connection

Main이 사용자·기기 인증과 서버 연결을 소유한다. 완료 발화의 음성 업로드와 TTS 오디오 수신은 이 연결을 통해 수행하고, 명령 수령과 결과 보고는 REST 폴링 계약을 따른다. Media Renderer에는 인증 자격 증명이나 범용 네트워크·IPC API를 노출하지 않는다.

공통 서버 클라이언트(`server-client.ts`)와 주소 설정·오류 변환·ID·시계 보정을 구현했다(F-027). 인증·대화·명령 어댑터는 이 위에 올라가는 후속 작업이며 아직 앱 시작과 연결하지 않았다. 구현 현황과 전송 계약은 [서버 연동 문서](../../../docs/architecture/server-integration.md#구현-현황-공통-서버-클라이언트)를 따른다.
